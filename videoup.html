CÔNG CỤ TÌM VIDEO

Tìm video theo từ khóa & lượt xem

Tìm video trên YouTube qua API của Google, lọc theo số view, xem trực tiếp ngay trên trang, kiểm tra quyền nhúng và gắn link sản phẩm Shopee vào từng video.

Kết quả

Vì sao chỉ có YouTube? YouTube có API tìm kiếm công khai (Google cung cấp). TikTok và Facebook không mở API tìm video theo từ khóa cho mục đích này, nên không thể làm tương tự một cách hợp lệ. Công cụ này tập trung làm tốt phần YouTube.
Về "quyền xem / đăng lại": Nhãn Cho phép nhúng nghĩa là chủ video bật chế độ nhúng — bạn được hiển thị video trên trang. Nhãn Creative Commons là video cho phép dùng lại theo giấy phép CC. Còn tải về rồi đăng lại là vấn đề bản quyền riêng, công cụ không thể tự khẳng định — hãy tự xác minh trước khi sử dụng lại.
Hướng dẫn lấy API key (miễn phí) — bấm để mở
  1. Vào Google Cloud Console, đăng nhập tài khoản Google.
  2. Tạo một dự án mới (Project).
  3. Vào APIs & Services → Library, tìm YouTube Data API v3 và bấm Enable.
  4. Vào APIs & Services → Credentials → Create credentials → API key, sao chép key dán vào ô phía trên.
  5. Bảo mật key: bấm vào key → Application restrictions → HTTP referrers, thêm tên miền GitHub Pages của bạn (vd tên.github.io/*) để người khác không dùng trộm key.

Hạn mức miễn phí: ~10.000 đơn vị/ngày. Mỗi lần tìm tốn 100 đơn vị, nên bật "Tìm kỹ" sẽ tốn nhiều hơn. Hết hạn mức thì chờ sang ngày hôm sau hoặc xin tăng quota.
